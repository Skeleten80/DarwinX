# DarwinX Tests

DarwinX uses tests as milestone gates rather than as an afterthought.

Planned layers:
- host-side build/source verification;
- kernel smoke and regression tests;
- userspace runtime tests;
- system-service integration tests;
- framework API tests;
- UI/compositor tests;
- hardware-target qualification suites.

A feature is not considered supported on a target until its relevant tests and recovery path are documented.
